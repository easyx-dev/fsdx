这个项目当前是基于 [TanstackStart](https://tanstack.com/start/latest/docs/framework/react/overview) 初始化的模板。我要基于这个工程继续开发出一套内容管理系统，接下来我需要进行头脑风暴，进行系统设计。下面是必要的模块其他的你来补充。

- 日志模块
  - 日志支持文件落地
  - 支持切割日志（默认配置为按天切割）
  - 支持管理端查库日志
- 双用户表
  - 管理员用户
    - 登录注册
    - 角色权限
      -（RBAC 权限模型）
    - 用户管理
  - 客户端用户
    - 登录注册
- 字典管理
  - 支持字典预置
  - 系统缓存避免频繁查库
- 系统配置
  - 支持预置配置
  - 系统缓存避免频繁查库
- 文件管理
  - 支持秒传 SHA256 校验
  - 支持临时文件上传（业务落库时将文件转为永久）
  - 过期文件自动删除
  - 支持文件下载
